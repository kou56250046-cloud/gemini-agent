各スライドの量と、補助の要素（box・note・source・conclusion）の使い分けを次のとおりにしてください。
描画ツールは、量が少なければ文字を大きくして枠を埋め、多ければ文字を小さくします。読みやすいのは、下の「目安」に近い量です。

# type ごとの量の目安
| type | 少なすぎ（まとめる） | 目安 | 多すぎるときの対処 |
|---|---|---|---|
| summary | 2項目以下 | 4項目。各 text は2行以内 | 詳細は本編へ |
| content | 2項目以下 | bullets 4〜6項目。入れ子は1段まで | 2枚に分ける。補足は box へ |
| compare | 片側2項目以下 | 左右とも3〜4項目 | 差のない観点を削る |
| table | 2行以下 | 3〜6行×3〜5列。セル30字以内 | 行を絞り、残りは Appendix |
| flow | 4ノード以下 | 6〜12ノード | 全体図と詳細図に分ける |
| schedule | 3行以下 | タスク5〜10行 | group でまとめる |
| issues | 1行 | 3〜5行 | 優先度の高いものだけ |
| conclusion | － | points 3つ、next 3つ | － |

「少なすぎ」のスライドは、前後の近い内容とまとめるか、根拠（数値・具体例・条件）を足して目安に近づけてください。

# 補助の要素の使い分け
| 要素 | 使うとき | 書かないこと |
|---|---|---|
| `box`（content の右の囲み） | 本文を補う「対象外」「前提」「ポイント」を3項目以上 | 本文の繰り返し、1〜2項目だけの囲み |
| `conclusion`（compare の下の帯） | 比較から導いた推奨を1文 | 比較の要約 |
| `note`（図表の下の注記） | 数値の条件・定義・例外を1行 | 主張 |
| `source`（出典） | 数値を載せたスライドには必ず | － |

# 目次
- 章扉（section）が2つ以上あれば、表紙の次に目次が自動で入る（章ごとにスライドの題名とページ番号）
- 自分で目次の項目を決めたいときだけ `{ "type": "toc", "items": ["章1", "章2"] }` を書く（この場合はページ番号が付かない）

# スライドを分ける基準
- 論点が2つある（lead に「また」「さらに」が入る）
- 描画ツールが「文字が枠からあふれています」と警告した
- 図表を2つ置きたい

# Appendix に回す基準
- 意思決定に直接は要らないが、根拠として残したい詳細（明細表、試算の内訳）
- `appendix: true` を付け、本編の最後（まとめの後）に置く。目次では「Appendix」としてまとめて載る
