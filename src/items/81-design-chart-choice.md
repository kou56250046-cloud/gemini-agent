スライドの type は、**伝えたいこと**から次の表で選んでください。

| 伝えたいこと | 使う type | 書き方のポイント |
|---|---|---|
| 全体の要約 | `summary` | 課題・提案・効果・進め方の4項目 |
| 主張と根拠（文章が中心） | `content` | 箇条書き6項目まで。補足は box |
| 2つの案の比較 | `compare` | conclusion に推奨を書く |
| 3つ以上の案の比較・属性の一覧 | `table` | 1行1案、列は比較の観点 |
| 数値の比較・推移（前後比較、月別の件数など） | `table` | 期間や案を列か行に並べ、注目する数値を太字に |
| 手順・業務の流れ・判断の分岐 | `flow` | 担当ごとにレーンを分ける |
| 日程・工程 | `schedule` | マイルストーンを3つ前後 |
| 課題と対策の対応 | `issues` | 5行まで |
| 結論と次の行動 | `conclusion` | points 3つ、next 3つ |

# 使ってはいけない組み合わせ
- グラフを使う（chart・pie などの type はない）→ 数値は table で示し、lead で傾向を言葉にする
- 文章を表のセルに詰め込む → 箇条書き（content）にする
- 1枚に図表を2つ以上置く → スライドを分ける
- 2案しかないのに table にする → compare を使う
