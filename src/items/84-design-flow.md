フロー図は次の規則で書いてください。配置は描画ツールが自動で行いますが、書く順番と量で見やすさが決まります。

# 量
- スライドに載せる図：12ノード・8段（横に並ぶ数）・レーン5本まで
- 超える場合は、全体の流れ（粗い図）と、詳しい部分（別の図）に分ける。詳しくした部分は全体の図で `sub` にする

# 書く順番（配置に効く）
- **主な流れ（正常に進む経路）を先に書く。** ノードも矢印も、主経路を先に、例外や差し戻しを後に書く
- レーンは、最初に作業する担当を上にする（例：顧客 → 営業 → システム → 倉庫）
- 1つのレーンの中で同じ段に箱が並ぶと縦に積まれる。並ぶ必要のない箱は前後の段にずらす

# ラベル
- ノードのラベルは「動詞で終わる短い文」にする（例：「注文内容を確認する」→「注文を確認」）。12字以内
- 分岐（decision）は「〜か」で終わる問いにし、出る矢印に必ず「はい / いいえ」などのラベルを付ける
- 矢印のラベルは6字以内
- 補足は `note` に書く（図の下に ※番号で載る）。ラベルを長くしない

# 種類の使い分け
- 人の作業は `task`、システムへの登録・データは `data`、帳票の出力は `doc`、別の図で詳しく書く処理は `sub`
- 開始と終了は1つずつにする（終わり方が複数あるときは、終了の前で合流させる）

# スライドにするとき
- lead には、図から分かること（ボトルネック、手戻り、待ち時間）を書く
- 課題のある箇所は note で「※1 ここで平均2日待つ」のように示す
