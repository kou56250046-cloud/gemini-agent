表は次の規則で作ってください。描画ツールが見出し行の色・縞模様・文字の大きさを自動で決めます。

# 構成
- 列は5つまで、行は6行まで（見出し行を除く）。超えるならスライドを分けるか、重要な行だけを残して残りを Appendix に回す
- 1列目は「行を見分ける名前」（案の名前・項目名）にする
- 列の順番は「名前 → 判断に使う観点 → 結論」の順にする
- 合計・推奨の行は `**太字**` にする（例：`"**合計**"`、`"**1,200**"`）

# セルの中身
- 1セル1情報。2つ以上のことを書くなら列を分ける
- セルは30字以内。長い説明は表の下の `note` か、別の content スライドに書く
- 数値の列は単位を列名に書き（例：「金額（万円）」）、セルには数値だけを書く。3桁区切りのカンマを付ける
- 「○ / △ / ×」で評価する場合は、表の下の note に基準を書く
- 空欄は作らない。該当しなければ「－」と書く

# 列幅
- `widths` に列幅の比を書ける（例：`[20, 55, 25]`）。文章の多い列を広くする
- 書かなければ文字数から自動で決まる

# 表とほかの type の使い分け
- 数値の大小・推移を見せたい → table のまま、注目する数値を太字にし、傾向は lead に言葉で書く（グラフは使えない）
- 2案の比較 → compare（3案以上なら table）
- 課題・原因・対応・担当・期限 → issues（列が決まっている）
- 文章が中心 → content の箇条書き
