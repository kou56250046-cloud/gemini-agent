# 弾4：監査ログ＋質問箱の自動化＋会議の議事録＋拡張の追加機能

承認済み計画：`~/.claude/plans/gemini-claude-code-gemini-notebooklm-valiant-lemon.md`（弾4）

## 背景
- 「どこでどんな処理が行われ、どこまで進んでいるか」を後から確かめられる記録が無い
- 会議の議事録づくりと、NotebookLM の質問箱（質問 → ブロック形式の回答 → qa-box に貼る）に、貼り付けの手間が残っている
- 拡張でさらに手間を減らしたい：会話の記録、入力欄の定型文、Gem の指示文の更新、朝の確認、ページの取り込み

## 受入条件
1. 監査ログ：
   - 置き場所：案件フォルダの `case/audit/YYYY-MM.jsonl` に追記する
   - 項目：時刻・依頼の ID・順番・誰が・どこで・何を・道具・対象・結果・段階・sha256・文字数・所要時間・前の行のハッシュ
   - 本文は入れない
   - 検証：改ざん・欠番・順序の乱れを見つける
   - 集計：段階ごとの到達時刻と所要時間を出せる。CSV に書き出せる
   - 監査タブ：時系列・進み具合・絞り込み・検証・CSV
2. いま何をしているか（待機・送信中・生成中と経過秒・道具の実行中・人の返事待ち・許可待ち）を、パネルの上に常に出す
3. 会話アーカイブ：送信と受信を `case/会話/` に記録する（設定でオフにできる）。sha256 が監査ログと一致する
4. スラッシュコマンド：Gemini の入力欄で `/仕様` などのあとに Tab を押すと、決まった文になる
5. 会議：
   - 記録：Meet の字幕を記録して、話者・時刻つきの文字起こしにする。伸びる字幕を確定させ、重複をまとめる
   - 取り込み：VTT・Teams・「話者：本文」の形も取り込める
   - 発言量：発言者ごとの発言数・文字数・割合を出す
   - 議事録の生成：長いものは分けて Gemini に送る
     - 返ってくる中身：議事録（会議の情報・目的と結論・決定・宿題・未決・話題と時刻・発言者ごとの要約・次回の議題と顧客への確認事項）、memo、宿題の表
     - 保存：md・docx・xlsx で保存し、案件メモに反映する
6. 質問箱：
   - 部品：qa-box の parse / model を写して使い、qa-box のテストを通す
   - 送る：質問を NotebookLM に送る（3000 字ごとに分ける）
   - 取り込み：回答を取り込み、新しい質問は自動で入れる。更新は差分を見て反映・新規・見送りを選ぶ
   - その他の操作：
     - まとめて聞き直す
     - 案件メモへ反映する（二重にしない）
     - 確定した Q&A を NotebookLM 用 md に書き出す
     - 一覧を表・xlsx で出す
     - qa-box の JSON を読み込む
   - 保存：案件フォルダの `case/qa.json`。HTML 版はブラウザ内に保存し、貼り付けで使う
7. Gem の編集画面に、最新の指示文を流し込む（保存ボタンは押さない）
8. 朝の確認：決めた時刻に通知する。パネルに今日の確認（期限・止まっている案件・返事待ち）を出す
9. ページの取り込み：右クリックで、表示中のページの本文を `資料/取り込み/` に保存する
10. 権限は計画で足すものだけにする
    - 足す権限：alarms・notifications・contextMenus・activeTab
    - 足す host：meet.google.com
    - 通信は CSP で止めたまま

## 非目標
- 監査ログに本文を入れること、外部へ送ること、暗号化・署名
- 送信前の機密チェック
- qa-box.html を変えること
- ソースの自動アップロード
- Meet の音声の扱い
- 会議中の自動の議事録づくり
- Gem の保存・知識ファイルの自動アップロード
- service worker から案件フォルダを読み書きすること
