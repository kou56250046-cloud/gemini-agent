# 弾2：新しい型（構成図・論点マップ・WBS・解説ページ・Excel/VBA）

承認済み計画：`~/.claude/plans/gemini-claude-code-gemini-notebooklm-valiant-lemon.md`

## 背景
案件理解・アイデア出し・構成図・WBS・資料の HTML 化・Excel 作業を、毎回同じ品質で作りたい。
Gem には中身（決まった記法・JSON）だけを書かせ、見た目は gemini-agent の固定の描画で作る。

## 受入条件
1. 構成図（```arch）：
   - 描くもの：層の帯、ノード（四角・DB・人・社外の 4 つの形）、境界の枠、実線と点線の矢印、ラベル、添え書き
   - 守ること：
     - ノードは重ならない
     - 枠の中に枠の外のノードが入らない
     - 2 層以上飛ばす矢印は、途中のノードを横切らない
   - 書き間違いは行番号つきで知らせる
2. 論点マップ・選択肢の木（```map）：
   - 字下げの箇条書きを、左から右への木にする
   - 印（課題・案・推奨・要確認・リスク・済）は、色に加えて文字の札でも示す
   - 箱は重ならず、親は子の中央に来る
3. WBS（```wbs、または WBS の見出しの表）：
   - 日程：開始・終了が無ければ、依存の後から工数 8h = 1 日で営業日（土日を除く）を引く
   - 親子：親の依存は子全部に効く。親は子の範囲と工数の合計を持つ
   - 余裕：余裕（日）とクリティカルパスを出す
   - 書き間違い：循環・重複・見出し違い・無い依存・80h 超・8h 未満を知らせる
   - 出すもの：ガント図 SVG と xlsx。xlsx は 9 列＋日の列で、作業・余裕のない作業・親・土日を塗り分け、行と列を固定する
4. 解説ページ（```explain の JSON）：
   - 型：「結論（3 つまで）→ 全体像の図 → 詳細 → 次の一手」の HTML 1 枚
   - 図：flow / arch / map / wbs / table を SVG・表で埋め込む
   - スクリプトも外部参照も入れない（CSP で止める）
   - 欠け（結論・次の一手）と多すぎる結論を警告する
5. Gem の知識ファイル：
   - 記法 4 本（構成図・論点マップ・WBS・解説ページ）を足す
   - Excel・VBA の規則（数式を先に・控え・確認・件数・エラーの貼り戻し）を足す
   - 汎用の取り込みマクロを足す
   - 司令塔 Gem の知識ファイルは 10 個以内に収める
6. 案件メモ（```memo）：F/D/Q の ID で統合し、回答済にできる。状況（status.md）・成果物の一覧（index.md）・NotebookLM 用 md を作れる
7. 画面：
   - 「図」タブ（フロー図・構成図・論点マップを自動で判定）・WBS タブ・解説ページタブがある
   - 取り込みタブで新しいブロックを見分ける
   - 幅 390px で横にはみ出さない

## 非目標
- 祝日・休暇・人ごとの稼働率は日程に入れない（日付の決まった作業は開始・終了を書く）
- WBS の進捗を追う管理機能
- 構成図の自由な配置（座標の指定）・手で動かす編集
- 解説ページの見た目の切り替え（テーマ）
- VBA を拡張や画面から直接動かすこと（人が VBE に貼って実行する）
- WBS を PPTX の 1 枚にする出口（PNG を貼る。計画からの変更）
